# Кодекс — оглавление

Слой, в котором разрозненные мысли из `Notes/Thy Kingdom/` сведены в одну структуру. Исходные заметки **не переписываются**: Кодекс ссылается на них и раскладывает их содержимое по полочкам, чтобы у каждой мысли было одно место и один статус.

## Зачем этот слой

В `Gameplay/` лежат заметки-идеи: короткие, разной степени готовности, часть — пустые заглушки. Это нормально для склада мыслей, но по ним нельзя работать: непонятно, что делать сейчас, что потом, а что решено не делать никогда.

Кодекс отвечает на эти вопросы. Главное правило:

> **Новая мысль не переписывает Кодекс — она получает в нём строку.**

## Статусы

| Статус   | Значение                                                     |
| -------- | ------------------------------------------------------------ |
| `m1`     | нужно для рубежа M1 — «живой мир» на движке времени          |
| `m2`     | нужно для рубежа M2 — здания и взаимодействия                |
| `demo`   | нужно для публичного демо (аванпост → первое крупное здание) |
| `next`   | после демо, до релиза                                        |
| `maybe`  | возможно, но решение не принято                              |
| `parked` | не сейчас; вернуться позже                                   |
| `cut`    | решено не делать (с причиной)                                |

## Заметки Кодекса

- [[01 Vision]] — что это за игра, одним куском
- [[02 Milestones]] — рубежи M1 / M2 / демо с критериями приёмки
- [[03 Mechanics register]] — все механики из заметок, со статусами
- [[04 Glossary]] — термины: русский / английский / определение
- [[05 Open decisions]] — решения: принятые и открытые
- [[06 Simulation loop]] — шаг симуляции и очередь изменений
- [[07 Что описать]] — чего не хватает в описании игры, по цене откладывания

## Правила ведения

1. Мысль сначала появляется в `Gameplay/` как есть, потом строкой в [[03 Mechanics register]].
2. У каждой механики указан источник — так Кодекс остаётся проверяемым.
3. **Изменение статуса и есть решение.** Статус без причины не меняется.
4. Заметки Кодекса — по-русски. Код, имена в коде и английские термины — по-английски.
5. Пустая заметка в `Gameplay/` — это не ошибка, а объявленная неизвестность. Она попадает в [[05 Open decisions]] как вопрос.
6. **Технические термины не транслитерируются.** Пишется `callback`, а не «колбэк». При первом употреблении можно дать пояснение по-русски.
7. **Абзац пишется одной строкой.** Переносов внутри предложения нет: строка заканчивается только там, где заканчивается абзац или элемент списка.
