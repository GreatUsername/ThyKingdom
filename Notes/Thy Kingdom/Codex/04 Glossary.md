## Термины объектов

| Русский                  | English       | Определение                                                                          |
| ------------------------ | ------------- | ------------------------------------------------------------------------------------ |
| статические данные       | static data   | таблица определений: неизменяемые свойства объекта                                   |
| guid                     | guid          | стабильный идентификатор, **определяющий статические данные** объекта                |
| тип объекта              | type-id       | компактное число вместо `guid`: ссылаться по числу проще и дешевле                   |
| идентификатор отрисовки  | render-id     | числовой идентификатор для отрисовки; намеренно не совпадает с `type-id`             |
| флаг                     | flag          | константный признак на базовом классе, выведенный из статических данных при создании |
| базовый класс            | base class    | общий интерфейс объекта: подвижность, флаги, `realObjectType()`                      |
| специализированный класс | derived class | уточняет поведение там, где общего случая недостаточно                               |
| коллайдер                | collider      | форма объекта для столкновений; хранится в данных симуляции                          |
| широкая фаза             | broad phase   | проверка габаритных боксов                                                           |
| узкая фаза               | narrow phase  | проверка точной формы после пересечения боксов                                       |

**Зачем три идентификатора.** Все три существуют ради скорости: `guid` — стабильный ключ, по которому определяются статические данные; `type-id` и `render-id` — компактные числа для быстрых обращений вместо работы с `guid`. `type-id` и `render-id` специально не совпадают: несколько разных типов объектов могут использовать один набор текстур, если выглядят одинаково.

## О названиях

Два термина требуют решения, потому что они **анахроничны для XIII–XV века**: `губерния` учреждена в России в 1708 году, `губернатор` — её производное. Для Европы этого периода нужен термин, который значит «земля и её держатель».

Варианты и рекомендация — в [[05 Open decisions]], ОД-1.

## Устойчивые предпочтения

- `округа` → **`местность`**. Заменено по всему Кодексу и в заметках.
- **`местность` ≠ `окрестность`.** Местность — это земля вообще. Окрестность (vicinity) принадлежит конкретному зданию и является зоной его влияния. Это разные термины, и путать их нельзя.
