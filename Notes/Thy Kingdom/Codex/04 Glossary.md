# Глоссарий

Один термин — одно значение. Русский вариант — для заметок, английский — для кода и строк игры.

## Термины мира

| Русский | English | Определение |
|---|---|---|
| аванпост | outpost | первый уровень развития владения; стартовое состояние демо |
| деревня | village | второй уровень развития владения |
| губерния | *(спорно, см. ОД-1)* | владение на макроплане; единица собственности |
| губернатор | *(спорно, см. ОД-1)* | правитель владения |

## О названиях

Два термина требуют решения, потому что они **анахроничны для XIII–XV века**:
`губерния` учреждена в России в 1708 году, `губернатор` — её производное.
Для Европы этого периода нужен термин, который значит «земля и её держатель».

Варианты и рекомендация — в [[05 Open decisions]], ОД-1.
