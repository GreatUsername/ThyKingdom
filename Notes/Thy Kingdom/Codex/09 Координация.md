# Координация агентов

## Канала сообщений нет

Агенты не видят друг друга напрямую. Ассистент может писать только тем агентам, которых запустил сам; агенты, запущенные автором отдельно, для него не существуют — их нет ни в его дереве, ни в списке запущенных. В обратную сторону так же.

Значит, единственный общий канал — **файловая система**. Всё, что должно дойти до другого агента, должно быть записано в файл, который тот прочитает. «Я ему передал» не работает: передать нечем.

## Почему не одна рабочая копия

Несколько агентов в одном рабочем каталоге ломаются на трёх вещах, и ни одна из них не про логику:

- **индекс git**: одновременный `git add` упирается в lock и падает;
- **каталог сборки**: CMake и make не рассчитаны на параллельные вызовы в одном каталоге;
- **пересечение файлов**: два агента в одном файле — потерянная работа одного из них.

Поэтому у каждого агента своя рабочая копия через `git worktree`. Она делит базу объектов, поэтому коммиты сливаются чисто, но индекс, каталог сборки и файлы у неё свои.

```
git worktree add K:\ThyKingdomGame\agents\<имя> -b agent/<имя>
```

## Правила

1. **Один файл — один писатель.** Ни один файл не общий на запись.
2. **Заявка до работы.** Агент объявляет файлы в `.agents/claims/<имя>.md` и не берёт занятые.
3. **Кодекс правит только Летописец.** Остальные предлагают правку в своём отчёте.
4. **Слияние делает Летописец.** Агенты коммитят в свои ветки; в `codex` вливает один, иначе история превращается в кашу.
5. **Приёмка — команды, а не слова.** Пакет работы из [[08 Тесты и инженерия]] задаёт, что запускать и что считать успехом.

## Роли

Роли и границы — в [[08 Тесты и инженерия]], раздел «Работа с агентами». Там же пакет работы: пять полей, без которых задание возвращается на переделку.

## Что где лежит

| Путь                       | Что это                                             |
| -------------------------- | --------------------------------------------------- |
| `.agents/README.md`        | протокол в одну страницу; агент читает его первым   |
| `.agents/claims/<имя>.md`  | заявка: что занято и с какого момента               |
| `.agents/notes/<имя>.md`   | отчёты, дописываются в конец                        |
| `Notes/Thy Kingdom/Codex/` | долговременная память: замысел, решения, соглашения |

`.agents/` не версионируется: это живая переписка, а не история. Всё, что должно пережить сессию, Летописец переносит в Кодекс.
