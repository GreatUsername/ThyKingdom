*(Anno, Cities Skylines)*

Овладев ячейкой сегмента, игрок получает ячейки строительства, которые нужны для строительства новых зданий. Новые здания будут размещены в данной ячейке.

Ячейка проходит следующую цепочку развития: аванпост-деревня-губерния

У губернии есть очередь строительства для постройки зданий. 

Юнитов будут генерировать определённые здания и их количество будет ограничено.

В губернии можно строить торговые маршруты.

Формирование нескольких ячеек в одну зону на которую будет распространяться policy
